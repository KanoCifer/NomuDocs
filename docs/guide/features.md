# 功能总览

Nomu 围绕「货源商品 → Noon 已上架商品」这一条主线展开，店铺管理、批量复制、AI 生图、目录浏览、任务跟踪也都在同一条流水线上。这一页是全部能力的索引，每一项都链到详细说明。

## 主线：采集 → 上架

| 环节 | 能力 | 详见 |
| --- | --- | --- |
| 源商品采集 | 1688 / 淘宝 / 天猫 / 京东 / noon.com 商品页一键抓取，标题、图集、规格变体、价格一次拿全 | [快速上手](./quick-start) |
| 字段编辑 | 单商品抽屉逐条确认，调价、改币种、换类目、改品牌、套用模板 | [快速上手](./quick-start) |
| AI 翻译 | 中译英 / 阿拉伯语，标题与卖点自动翻译，适配 UAE 与沙特两站 | [快速上手](./quick-start) · [账户与积分](./account) |
| 合规建图 | 商品图自动处理成 Noon 规格（宽 ≥ 660px、宽高比 ≥ 0.5、≤ 10MB JPEG） | [快速上手](./quick-start) |
| AI 生图 | NomuDesign 画布跑商品图，可选模型、优化提示词、一键应用到商品 | [NomuDesign](./nomu-design) |
| 上架 | 每件商品一条独立任务，按固定步骤走完：建品 → 传图 → 写属性 → 定价 → 库存 → 上架。一件失败不影响其他件 | [快速上手](./quick-start) |
| 归组上架 | 同品牌多件商品按规格轴（尺码 / 型号 / 颜色）归并成一组发布 | [归组与尺寸变体组](./group-and-sizes) |
| 尺寸变体组 | 尺码并进单商品上架表单，父品和子品一次提交 | [归组与尺寸变体组](./group-and-sizes) |
| 条码标签打印 | 给自有 SKU 打条码标签（Code 128 / EAN-13 / UPC-A），独立页面逐张预览打印或导出 PNG / SVG，助手里一句话生成整批并打包 ZIP | [条码标签打印](./barcode-labels) |
| 复制商品 | 按源 PSKU 复制 Noon 已上架商品，单件 / 批量 / 跨设备 | [复制商品](./duplicate) |

## 通用保障

- **只连白名单站点**，扩展只向你列出的站点发请求，白名单之外的地址一律不发
- **数据存在本地**，店铺、批次草稿和 NomuDesign 草稿都存在你的浏览器里。登录后账户令牌和 AI 调用的上行内容会发给账户服务，详见[隐私政策](/privacy/)
- **Cookie 通道**，通过你浏览器里已登录的 Noon 会话直接操作，不用申请 Noon 密钥，Nomu 自己不存 Noon 凭证
