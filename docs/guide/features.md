# 功能总览

Nomu 围绕「1688 / noon 源商品 → Noon 已上架」一条主线展开，并把日常运营会用到的店铺管理、批量复制、AI 生图、目录浏览、任务跟踪等都装进同一条流水线。这一页是各能力的索引与速览，每项能力都链接到详细说明。

## 主线：采集 → 上架

| 环节 | 能力 | 详见 |
| --- | --- | --- |
| 源商品采集 | 1688 / noon.com 源页一键抓取，标题、图集、规格变体、价格一站落地 | [快速上手](./quick-start) |
| 字段编辑 | 单商品抽屉逐条确认，可调价、改币种、换类目、改品牌、套用模板 | [快速上手](./quick-start) |
| AI 翻译 | 中译英 / 阿拉伯语，标题与卖点自动翻译，适配 UAE / Saudi 两站 | [快速上手](./quick-start) · [账户与积分](./account) |
| 合规建图 | 商品图自动处理为 Noon 规格（宽 ≥ 660px、宽高比 ≥ 0.5、≤ 10MB JPEG） | [快速上手](./quick-start) |
| AI 生图 | 独立画布 NomuDesign 跑商品图，覆盖模型选择、提示词优化、应用到商品 | [NomuDesign](./nomu-design) |
| 上架流水线 | 声明式步骤表驱动单商品走完 `product/create` → `activate` + `warranty` 全链路 | [快速上手](./quick-start) |
| 归组上架 | 同品牌多件商品按规格轴（尺码 / 型号 / 颜色）归并成组发布 | [归组与尺寸变体组](./group-and-sizes) |
| 尺寸变体组 | 父品挂 size 子品变体，父品未上架由后端兜底 | [归组与尺寸变体组](./group-and-sizes) |
| 复制商品 | 通过 PartnerSku 复制 Noon 已上架商品，单件 / 批量 / 模板 | [复制商品](./duplicate) |

## 通用保障

- **请求白名单**：所有 Noon / 1688 / Nomu 后端请求 URL 由白名单唯一门控，白名单外一律不放行。
- **数据本地化**：店铺记录、批次草稿、NomuDesign 草稿、Nomu 账户令牌全部保存在浏览器本地；无埋点、无统计、无追踪。详见 [隐私政策](/privacy/)。
- **Cookie 通道**：通过你浏览器中已登录的 Noon 会话直接操作，Nomu 自身不存 Noon 凭证。
- **夜间模式**：界面跟随系统 `prefers-color-scheme: dark`。
