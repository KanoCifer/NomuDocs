# 获取支持

用的时候卡住了，或者有功能想提，直接联系我。

## 联系方式

最快的是微信。扫码添加好友，备注「Nomu」：

![微信](/support-wechat-qr.jpg)

![企微](/wechat-wu.jpg)

飞书也可以扫：

![飞书](/feishu.jpeg)

## 反馈问题时，带上这些信息

带上这三样，我定位得更快：

- **Nomu 版本号**：在扩展管理页（`chrome://extensions`）看得到
- **做了什么**：从哪一步开始出问题（采集 / 确认 / 发布）
- **现象**：报错提示、截图，或者任务面板里失败任务的状态。失败那件展开后点「复制错误」，那段文本直接贴过来就行

安装相关的问题先看[安装 Nomu](/guide/install) 的常见问题。
