# 获取支持

用的时候遇到问题，或者有功能想提，都可以直接联系我。

## 联系方式

最快的方式是微信。扫码添加好友，备注「Nomu」：

![微信](./images/support-wechat-qr.jpg)

## 反馈问题时，带上这些信息

描述得越具体，问题越快解决：

- **Nomu 版本号**：在扩展管理页（`chrome://extensions`）可以看到
- **做了什么**：从哪一步开始出问题（采集 / 确认 / 发布）
- **现象**：报错提示、截图，或任务面板里失败任务的状态

安装相关的问题先看[安装 Nomu](/guide/install) 的常见疑问。
