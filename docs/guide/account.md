# 账户与 AI 积分

用 Nomu 的任何功能都要先登录 Nomu 账户。AI 翻译、NomuDesign 生图、提示词 AI 优化在登录之外还要消耗积分。

Nomu 账户和你的 Noon 卖家账户各是各的，登录 Nomu 不读、不动你的 Noon 会话。

## 哪些功能需要登录

除「计费」列标注消耗积分的行外，其余功能同样需要登录 Nomu 账户，只是不计费。

| 功能 | 需要登录 Nomu | 计费 |
| --- | --- | --- |
| 1688 / 淘宝 / 天猫 / 京东 / noon 源商品采集 | 是 | 免费 |
| 商品图本地合规处理 | 是 | 免费 |
| 上架流水线 | 是 | 免费 |
| 复制商品 | 是 | 免费 |
| 目录浏览 / 快捷搜索 | 是 | 免费 |
| 实时汇率 | 是 | 免费 |
| AI 翻译（中 → 英 / 阿） | 是 | 消耗积分 |
| NomuDesign 跑图 | 是 | 消耗积分 |
| 提示词 AI 优化 | 是 | 消耗积分 |

每次 AI 操作具体扣多少，看账户页的「积分单价」页签，那里的数字跟服务端价格表走，调价不用等文档更新。

未登录时，扩展各功能页整页显示登录墙，采集抽屉的表单与底部操作按钮被登录卡替换；宿主商品页（1688 / 淘宝 / 天猫 / 京东 / noon.com）本身不受影响，仍可正常浏览。

## 登录方式

打开「账户」扩展页（入口在工具条弹窗、操作菜单与在线状态弹窗），未登录时有两档 tab，都不需要密码：

- **邮件链接**：输入邮箱，后台把一次性登录链接发到邮箱，在浏览器点链接确认登录。链接 10 分钟内有效，页面上有剩余时间倒计时
- **验证码**：输入邮箱收到 6 位数字验证码（5 分钟内有效），填入即完成登录

用邮件链接登录要保持账户页开着，点完邮件里的按钮登录状态会自动同步过来。页面关掉就不再同步了。

账户页底部常驻两个外链，都指向官网：

- 「还没有账号？前往 nomu.kanocifer.chat 注册」→ <https://nomu.kanocifer.chat/register>
- 「忘记密码？前往 kanocifer.chat 重置」→ <https://nomu.kanocifer.chat/forgot-password>

**扩展内没有注册表单，也没有密码登录**，注册与密码重置都在官网上完成。

## 注册 Nomu 账号

注册页：<https://nomu.kanocifer.chat/register>

注册后才能使用 Nomu 的任何功能；AI 翻译、NomuDesign 生图与提示词优化在登录之外另需消耗积分。

1. 填用户名（3 到 50 个字符）、邮箱、密码（至少 6 位）与确认密码
2. 点验证码框右侧的「发送验证码」，从邮件里抄 6 位数字填进去；按钮随即进入 60 秒倒计时，走完才能重发
3. 点「注册」
4. 出现成功卡后，「去安装 Nomu」直接跳 Chrome 网上应用商店，「返回首页」回落地页

注册成功**不产生登录态**。要开始使用 Nomu，回扩展账户页用刚注册的邮箱登录一次即可（邮件链接 / 验证码任选）。

验证码是 6 位数字，前面可能有 0，别当成 5 位输。

## 忘记密码 / 重置密码

重置页：<https://nomu.kanocifer.chat/forgot-password>（账户页底部也有直达链接）。整页分两步。

**第 1 步 · 申请重置邮件**：填注册邮箱，点「发送重置邮件」。页面固定提示「若该邮箱已注册，重置邮件已发送」，邮箱没注册过也是这一句，一样进到下一步。

**第 2 步 · 校验并设新密码**：从邮件里抄 6 位验证码（5 分钟内有效），填新密码（至少 6 位，且不能与旧密码相同）与确认新密码，点「重置密码」。成功后出现成功卡，可直接去安装 Nomu。

- 邮箱填错了：步骤 2 顶部有「换个邮箱」，点它退回第 1 步重来
- 提示「验证码错误或邮箱未注册」：验证码错、已过期，或这个邮箱没注册过，三种情况页面给的是同一句话
- 提示「会话已过期，请重新申请验证码」：在两步之间刷新过页面，回到第 1 步重新申请
- 提示「请换一个未使用过的密码」：新密码与旧密码相同

## 会话与多设备

- **多设备模型**：同一账户最多可在 5 台设备上保持登录，新设备登录不会使旧设备的会话失效；每台设备登出只清除该设备自己的会话
- 登出后扩展、账户页、任务面板一起退出

## AI 积分卡

账户页第二张卡是「AI 积分」，展示余额和最近 10 条消费流水。流水里的来源分三类：

| 来源 | 含义 |
| --- | --- |
| 通用翻译 | AI 翻译扣的 |
| 提示词优化 | 提示词 AI 优化扣的 |
| NomuDesign 生图 | 跑图扣的，按张算 |

- 开页自动拉一次余额与流水
- 「刷新」按钮手动重拉
- 余额不足 / 操作过快 / 服务不可用等错误会明确提示

余额快见底或者数字对不上，来这里对照最近消费。同一次操作因为超时重试不会重复扣费，任务面板里失败的任务点重试也不会多扣。

> 详细的数据收集与积分规则见 [隐私政策](/privacy/)。

## 错误码

AI 请求失败时，弹窗会把错误信息原样显示出来，方便你定位问题：

| 错误 | 含义 | 建议 |
| --- | --- | --- |
| `auth_required` | 未登录 | 去账户页登录 |
| `auth_expired` | 登录过期 | 重新登录 |
| `insufficient_credits` | 积分不足 | 联系管理员充值 |

## 常见问题

### 登录后还是提示 `auth_required`？

先在账户页退出登录再登录一次。装过清理类扩展、浏览器做过数据清理的，也会让已登录状态丢掉，重新登录即可。

### 积分变负数？

余额是按服务端算的，出现负数大概率是有任务在跑还没扣完，刷新一下积分卡即可。

### 怎么注销 Nomu 账户？

账户页登出只退出这台设备上的登录；要彻底注销账户，邮件联系管理员。

### 注册完还要在扩展里登录吗？

要。注册只为建账号，不产生登录态；登录要在扩展账户页用邮箱登录一次，登录后才能使用全部功能。

### 收不到验证码邮件？

先翻垃圾邮件。验证码一次性且 5 分钟内有效，过期就重发一次；登录验证码另有限流，等一分钟再试。
