# 条码标签打印

给自有 SKU 生成条码标签的独立页面，从扩展工具条进入。选好编码格式和标签尺寸，填入 SKU、品牌、产地，就能看到实时预览，导出 PNG、SVG，或者把整批打成一个 ZIP。

## 两种用法

条码标签有两条路，产物一样，按场景挑：

| | [独立标签页](#进入方式) | [在助手里生成](#在助手里生成) |
| --- | --- | --- |
| 适合 | 手上有几件货，要看着预览逐张核对 | 手里有一列 SKU，一次要一整批 |
| 怎么说 | 填表、调参数、实时看预览 | 在 Nomu 助手里用一句话说要哪些编码 |
| 产物 | 逐张 PNG / SVG，或打包 ZIP | 一个 zip 下载链接 |
| 一次能出多少 | 一批几十张最顺手 | 单次最多 200 张 |
| 标签尺寸 | 只能选预设的 6 种 | 预设之外还能说任意毫米数（10 到 300mm） |

两条路用的是同一套规格，画出来的条码位置和粗细一致，同一组参数下切换不影响。

## 在助手里生成

在 [Nomu 助手](./nomu-assistant) 里直接说要哪些编码，助手会调工具生成整批标签，回你一个 zip 下载链接。例如：

> 帮我给这 12 个 SKU 打 50×30 的标签，品牌都写 Nomu，产地写中国

助手会先把要生成的条目列出来跟你确认，再生成。

**支持的规格**

| 项 | 取值 |
| --- | --- |
| 编码格式 | Code 128（默认）/ EAN-13 / UPC-A |
| 标签尺寸 | 40×20、50×30、60×40、70×50、80×60、100×60 mm，也可以直接说「45×25」这类任意毫米数，范围 10 到 300mm |
| 分辨率 | 固定 300 DPI，两条路都一样，没有选项 |
| 显示内容 | 条码下方的编码数字、品牌产出行，可以分别要求开或关 |

**与页面版的差别**

- **产物是 zip**：每张标签一份 SVG 加一份 PNG，印刷厂收位图、设计公司和不干胶厂要矢量，两种都在包里，不用点两遍下载。
- **一次一整批**：单次最多 200 张。超了助手会说明要分批，不会悄悄截断。
- **品牌和产地在每张标签上**：同一批货里不同品牌就分别填，不会图省事只填一个整批默认值。
- **非法项和重复项会跳过**：编码按补齐校验位后的结果去重，跳过了哪几条助手会一并告诉你，不影响其余标签生成。
- **标签规格不合适会被提醒**：条码窄到扫描枪认不出来时，助手会收到一条提示并转达给你，让你换更大的标签。你不会拿到一张打出来扫不出的标签。
- **zip 链接只保留约一周**，需要长期存档的当场下下来。

::: warning 需要登录
独立标签页与助手两条路都要登录 Nomu 账户才能用；未登录时点开只看到登录卡。
:::

## 进入方式

点扩展工具条上的**条码**按钮，打开独立的条码标签页。该页与「任务面板」一样是扩展的独立页面，可以单独开标签页或放到另一个窗口。

## 怎么用

1. **选编码格式**：Code 128（通用商品码）、EAN-13（欧洲零售码）、UPC-A（北美零售码）
2. **选标签尺寸**：40×20 / 50×30 / 60×40 / 70×50 / 80×60 / 100×60 mm，覆盖常见不干胶规格
3. **选模式**：
   - **单张**，填一个条码内容
   - **批量**，一次贴多行，每行一条，格式是 `SKU,品牌,产地`，比如 `SKU-0001,Speedo,Made in China`，品牌和产地留空也行
4. **填品牌与产地**：单张模式下这两行印在条码下方，可以留空
5. **调显示开关**：条码下方的编码数字、品牌产出行，各自独立开关
6. **导出**

右侧标签区域实时预览当前参数的效果。底部状态栏显示有效标签数、当前 DPI 下的点阵尺寸（dots），批量模式下有非法行时还会显示跳过数量。

## 导出方式

| 出口 | 用途 |
| --- | --- |
| **PNG** | 位图，按所选 DPI 与标签毫米数换算点阵，直接发标签打印机或插入文档 |
| **SVG** | 矢量图，任意放大不糊，适合交给设计或再加工 |
| **打包 ZIP** | 整批标签打成一个包，每张同时给 SVG 和 PNG |

## 编码规则与校验

- **Code 128**：支持大小写字母、数字与常用符号（ASCII 32 到 127），输错字符集时页面会提示
- **EAN-13**：只接受数字。给 12 位或 13 位都行，少的补前导零，末位校验位一律按数据位重算
- **UPC-A**：只接受数字。给 11 位或 12 位都行，补位规则同上
- 格式默认 Code 128，用户给的是 SKU 字符串就用它

非法或重复的批量行会被跳过，不影响其余标签生成，底部状态栏会告诉你跳过了几条。

## 常见问题

### 打印出来和预览对不上？

不会。预览、PNG、SVG、ZIP 四个出口用的是同一份版面计算，同一参数下画出的条码位置和粗细完全一致。

### ZPL 打印出来条码偏细或偏粗？

页面现在只出 PNG、SVG 和 ZIP，ZPL 和其他打印机指令流已经没有了。要批量打印，导出 PNG 送进打印机软件，条宽粗细按打印机手册调。

### 批量 PNG 标签数量有限制吗？

批量 PNG 导出为单张纵向长图，极大批量时会碰到浏览器 Canvas 的高度上限。标签多时建议分批导出。

### 中文品牌名打印出来是乱码？

用 PNG 导出。PNG 是位图，到哪台机器上打都不会串字体。

### 助手里生成的 zip 链接会过期吗？

会，链接指向服务器上的一个文件，保留期约一周。需要长期存档的当场下下来。

### 助手里说「要 500 张」会怎样？

单次上限 200 张。助手会告诉你要分批，你确认分几批之后各自生成，不会一次塞 500 张然后只给一部分。
