# 条码标签打印

给自有 SKU 打印条码标签的独立页面，从扩展工具条进入。选好编码格式与标签尺寸，填入 SKU、品牌、产地，即可生成标签预览，直接打印或导出给标签打印机使用。

## 进入方式

点扩展工具条上的**条码**按钮，打开独立的条码标签页。该页与「任务面板」「NomuDesign」一样是扩展的独立页面，可以单独开标签页或最小化到另一窗口，打印时不必来回切标签。

## 怎么用

1. **选编码格式**：Code 128（通用商品码）、EAN-13（欧洲零售码）、UPC-A（北美零售码）
2. **选标签尺寸**：40×20 / 50×30 / 60×40 / 70×50 / 80×60 / 100×60 mm，覆盖常见不干胶规格
3. **选分辨率**：203 DPI 或 300 DPI，按你的标签打印机选
4. **选模式**：
   - **单张**——填一个 SKU
   - **批量**——一次贴多行，每行一个 SKU，预览按行列出
5. **填品牌与产地**：这两行印在条码下方，可留空
6. **调显示开关**：边框、条码下方的编码数字、品牌产地行，各自独立开关
7. **导出或打印**

右侧标签区域实时预览当前参数的效果。底部状态栏显示有效标签数、当前 DPI 下的点阵尺寸（dots），批量模式下有非法行时还会显示跳过数量。

## 导出方式

| 出口 | 用途 |
| --- | --- |
| **打印** | 直接调浏览器打印。纸张尺寸自动跟随当前标签规格，无需在打印对话框里改纸张 |
| **SVG** | 矢量图，任意放大不糊，适合交给设计或再加工 |
| **PNG** | 位图，按所选 DPI 与标签毫米数换算点阵，直接发标签打印机或插入文档 |
| **ZPL** | 斑马码指令流，可直接送进 ZPL 标签机批量打印 |

## 编码规则与校验

- **Code 128**：支持大小写字母、数字与常用符号，输错字符集时页面会提示
- **EAN-13**：只接受数字。输入 12 位数据时自动补出第 13 位校验位；补位后会提示你「已自动补位」
- **UPC-A**：只接受数字。输入 11 位数据时自动补出第 12 位校验位

非法或重复的批量行会被跳过，不影响其余标签生成——底部状态栏会告诉你跳过了几条。

## 常见问题

### 打印出来和预览对不上？

不会。预览、SVG、PNG、ZPL 四个出口共用同一份版面几何计算，同一参数下画出的条码位置和粗细完全一致。

### ZPL 打印出来条码偏细或偏粗？

条码模块宽度按经验值生成，不同型号的标签机表现略有差异。遇到这种情况优先用 SVG 或 PNG 导出，按打印机手册调整。

### 批量 PNG 标签数量有限制吗？

批量 PNG 导出为单张纵向长图，极大批量时会碰到浏览器 Canvas 的高度上限。标签多时建议分批导出，或改用 ZPL 交给打印机直出。

### 中文品牌名打印出来是乱码？

ZPL 依赖打印机自带字库渲染中文，不同机型差异较大。需要可靠的中文标签时，用 PNG 导出。
