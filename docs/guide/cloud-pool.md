# 云端共享池与中转站

云端共享池是你账号下「跨设备流转采集结果」的中转站：在设备 A 上抓到的商品，不直接落本地库，而是推上云端池；设备 B 在线时能从浮岛看到，按需一键领取到本地再走正常上架流水线。

> 需要登录 Nomu 账户；中转站里的商品**不会写入本地批次**，只在领取后才落库。

## 入口与时机

| 入口 | 何时出现 |
| --- | --- |
| 采集抽屉「推送到中转站」按钮 | 已在源商品页完成抓取、还没入库前 |
| 页面底部「灵动岛」浮岛 | 任一页面都常驻，显示账号下中转站的在线状态与商品数 |

采集抽屉默认仍先落本地库；点「推送到中转站」才是把这一批从本地切到云端——两者是分开的写入路径，不会重复落库。

## 推送与领取

**推送端**

- 抓取完成后点「推送到中转站」，本批商品从本地批次列表移出，挂到云端池
- 中转站 header 显示「本账号在线设备数 / 在池商品数」
- 推送幂等：同一商品（按源 URL + 解析签名）二次推送不重复入库

**领取端**

- 灵动岛展开后能看到「同账号其它设备推送来的商品」
- 头部「一键领取」一次 reserve 全部 SKU 后顺序消费，避免编号空洞；逐条结果聚合回报
- 单条卡片右上角的领取按钮可以单独取
- 领取后商品落到领取设备的本地批次，按现有上架流水线继续走（编辑、归组、发布、复制都可以）

领取的 SKU 编号按领取端的店铺 PSKU 序号递增，不与推送端共享序号——这是「跨设备流转」而非「跨设备复制」。

## 灵动岛显隐

页面底部灵动岛可以单独关闭：

- 快捷菜单「更多」→ 「隐藏灵动岛」开关，跨会话保留
- 隐藏期间不显示中转站在线状态与商品数，但其它设备的推送仍正常入池；下次打开扩展时如果池里有未领取的商品，会以 toast 提示

> 同账号下，任一设备**不**安装 / **离线**超过一段时间会自动降级为离线态，不再占用在线名额。

## 离线与补发

- 推送端推送时如果对端离线，云端池照常入池
- 对端下次上线后灵动岛会显示积压项，按领取操作一次拉取
- 云端池里**未领取**的商品会保留一段时间（具体时长看服务端策略）；超过时限会被清理

## 适用场景

- **多机器分工**：一台机器专做采集（甚至不需要登录 Noon），推到中转站；另一台机器专做上架（已登录 Noon），从池里领取
- **临时换机**：原机器上的批次还没来得及发完，推到池里换机直接领取继续
- **临时解析**：右键「用 AI 解析」适配器生成的商品草稿可直接推池，不污染本地批次

## 与复制商品的区别

| 维度 | 云端共享池 / 中转站 | 复制商品 |
| --- | --- | --- |
| 推送方 | 任意一台采集端 | 必须有源 PSKU（已上架 Noon 商品） |
| 落库端 | 领取端的本地批次 | 目标 PartnerSku 的已上架商品（按 upsert 语义） |
| 走流程 | 领取后走采集 → 上架 | 入队即进入 publishTask 步骤表 |
| 是否需要登录 | 是 | 否 |

## 常见问题

### 推送后本地批次不见了？

推送是把商品从本地批次移到云端池，不是复制。如要保留本地副本，先正常入库，再单独推一份上池；目前没有「本地 + 云端同时留」的开关。

### 一键领取卡住？

一键领取是顺序消费；某条 SKU 因为网络抖动或对端限制 reserve 失败时，会显示该项失败原因，其余继续；不会出现「整批失败全部推脱」的情况。

### 灵动岛关掉还能领取吗？

可以。关闭灵动岛只是不常驻显示，不影响云端池本身的接收。重新打开灵动岛或直接进入采集抽屉即可看到积压项。
