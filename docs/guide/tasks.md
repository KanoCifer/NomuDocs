# 任务面板

任务面板是扩展的独立页面。在哪台设备上发布出去的、跑到第几步、卡在哪一步、能不能重试，都汇总在这里，不用守着上架抽屉等。

## 打开方式

三个入口：

- 工具栏点 Nomu 图标，弹窗里点「任务」
- Noon 卖家后台的操作菜单、右下角悬浮按钮里都有「任务面板」
- 总览台里的「任务」入口

每次打开都是新标签页，关掉就退出。

## 两类任务、两个视图

顶部切两个视图。两个视图各自记着自己的搜索词和筛选，来回切不丢：

- **普通任务**，单件商品和归组商品的发布。尺码变体是单件商品发布的最后一步，不单独立一条任务
- **复制任务**，按源 PSKU 复制 Noon 已上架的商品

### 发布任务有哪些状态

| 状态 | 什么时候看到它 |
| --- | --- |
| 等待中 | 已排进队列，还没开始跑 |
| 运行中 | 正在跑步骤 |
| 已完成 | 全部步骤跑完 |
| 失败 | 某一步失败，能看原因，可重试 |
| 已取消 | 你手动取消的 |

### 复制任务有哪些状态

| 状态 | 什么时候看到它 |
| --- | --- |
| 等待中 | 复制请求已收到，还没开始 |
| 已入队 | 复制已经做完，进了上架队列，进度去普通任务视图看 |
| 已推送 | 跨设备复制，对方已经收到，本机没落库 |
| 失败 | 复制没成功，展开看原因 |
| 已取消 | 你手动取消的 |

## 任务行展示什么

每一行是一件商品：

- 缩略图、商品标题、你的 SKU
- 状态点、国家（沙特 / 阿联酋）、任务类型（单品 / 归组）
- 当前跑到哪一步，以及每一步花了多久
- 归组商品还带组内件数、父 / 子角色和规格取值，见[归组与尺寸变体组](./group-and-sizes)

点行里非按钮的位置展开 / 收起，失败的那件默认展开。展开后是完整的步骤时间线，失败的那一步下面直接挂着错误码、错误信息、「已尝试 N 次」，以及「重试」和「复制错误」两个按钮。错误标了「可重试」才能点重试，标不了的重试按钮是灰的。

取消只对等待中的任务有用。已经在跑的任务要么跑完要么失败，等它出结果。

时间是相对时间（几分钟前、几小时前），鼠标停上去看绝对时间。

## 筛选

左侧边栏从上到下四块：

- **概览**，五个状态各有多少条，点一行只看那一个状态，再点一下恢复全看，底部是上架成功率。默认只看等待中、运行中和失败，已完成和已取消有计数但不显示，点那两行才看得到
- **任务类型**，单品 / 归组，可多选，默认全选
- **时间**，今天 / 7 天 / 10 天，默认近 7 天
- **批量操作**，「清空失败」「清空已完成」

顶部搜索框按标题或 PSKU 找，复制任务视图里搜源 / 目标 SKU。

## 加载与续跑

- 一次最多列出 200 条，底部出现「还有更早的任务，点击加载」，点一次往后翻一倍，翻到底按钮自己消失
- 任务在跑的时候列表自己刷新，不用手动刷页面
- 同一时间默认只跑 1 条上架任务，一批 50 件就得排一阵子。并发数和失败自动重试上限（默认 3 次）都在扩展设置里改

## 重试与清空

- **重试**，失败的那件点「重试」重新排队，跑成功的步骤自动跳过。同一次 AI 操作超时重试不会重复扣费，失败任务点重试也不会重复提交
- **清空已完成**，删掉本地已完成和已取消的上架任务，删之前有确认弹窗
- **清空失败**，删掉本地失败的上架任务。弹窗里还会列出这些任务在 Noon 上已经建出来的商品，默认连着一起删，不想要就取消勾选
- **清除任务**，复制任务视图里的按钮，删掉已结束的复制任务记录

## 错误定位

要反馈一个失败任务，把这几样一起发过来：点「复制错误」复制出的那段文本、商品标题和 SKU、国家和店铺。四样齐了基本不用来回问。

## Noon 登录态

任务面板和弹窗顶部都挂着 Noon 登录提示。没连上 Noon 时显示「未连接 Noon」，副标题写着「上次会话已过期 · 上架、同步、库存推送均暂停」，配「立即登录」「刷新」「稍后提醒」三个按钮。登录成功后自己消失，选了稍后提醒就这次会话里不再出现。

会话过期时上架、同步、库存推送都会停，任务会成片失败，所以先把它处理掉再提交。

Nomu 账户没登录时，这页整个换成登录墙，连这条提示都看不到。

## 与历史发布的关系

- 任务记录按任务各自保存，关浏览器、切店铺都不丢
- 回头改店铺配置不会改写已经跑过的任务，任务里记的是它跑那一刻的店铺信息
- 任务跑完后，商品在 Noon 上的真实 PSKU 记在这条发布记录里

## 常见问题

### 重试会重复扣费吗？

不会。同一次 AI 操作超时重试不会重复扣费，失败任务点重试也不会重复提交，跑成功的步骤还会自动跳过。

### 任务消失了？

先看筛选和时间窗。默认只看等待中、运行中和失败、近 7 天，落在窗口外或者已经完成的任务都不显示。也有可能被「清空已完成」「清空失败」清掉了，这两下删的是本地记录，删了找不回来。

### 失败任务能不能批量重试？

不能，一次只能重试一件。可以用概览把失败的那行筛出来，再逐个点重试。
