# 目录浏览

目录浏览是 Nomu 在 Noon 卖家目录（catalog）里挂的「在售/隐藏商品一览」侧栏。它不是 Noon 后台的替代品，而是**叠加在原页面上**的浏览面板：保留原页面所有信息，旁边再加一块可搜索、可翻页、可改卖家状态的视图。

## 打开方式

- 任意页面按 `Ctrl/⌘ + Shift + O`（[键盘快捷键](./shortcuts)）
- 操作菜单（Action Sheet）里的「目录浏览」入口
- popup 顶部「目录浏览」入口

打开后从屏幕侧边滑出抽屉，悬浮在原页面上方；关闭抽屉回到原页面，无导航跳转。

## 看什么

每一行展示一个 `CatalogOffer`——也就是 `offer/list/noon` 接口返回的一条 offer：

- 商品主图缩略图
- 标题
- PartnerSku
- 货币 / 价格（若有）
- 卖家状态 chip（在售 / 隐藏）
- 优化建议提示（`offer_issues`）

按 partnerSku / 标题子串搜索；搜索框 300ms debounce 静默期后生效。

## 翻页与状态

- 每页 20 条
- 抽屉打开且焦点不在输入框时，按 `←` / `→` 翻页
- 命中 limit 时底部显示「加载更早」按钮

状态机：

| 状态 | 含义 |
| --- | --- |
| `idle` | 初始态 |
| `no-active-store` | 没有激活店铺 → 提示去侧边栏选 |
| `missing-store-code` | 激活店铺缺 Noon Store Code → 提示补全 |
| `loading` | 拉取中 |
| `ready` | 拿到结果 |
| `error` | 接口报错，可点「重试」 |

## 改卖家状态

行内「在售 / 隐藏」开关走乐观更新——UI 立即翻转，请求失败回滚原态，请求成功重取当前页。响应里的 `psku[].is_active` 是权威值，写回 row 后与原 Noon 后台列表保持一致，避免状态偶尔不同步。

## 商品信息快速编辑

每一行右侧有铅笔按钮，点开调出「商品信息快速编辑」弹窗——对单条 offer 直接改标题、价格、库存、类目、品牌等字段，提交后走 publishTask 走最小变更路径，不动其它字段。

> 同一能力也挂在 [快捷搜索](./quick-search) 浮层里。

## 与任务面板的关系

目录浏览里改卖家状态是**即时生效**的（直接调 `offer/upsert/is_active-plp`），不进入 publishTask 步骤表——这是与「上架发布」不同的写路径。改了之后 100ms 之内 `db.changed` 推送回来，目录浏览与其它订阅同一资源的视图（如 [任务面板](./tasks)）会同步刷新。

## 与复制商品的关系

目录浏览**只读** + 改卖家状态；要复制到当前店铺，去操作菜单里走 [复制商品](./duplicate)——独立表单、独立任务，不在目录浏览里串行。

## 常见问题

### 列表是空的？

- `no-active-store` → 还没选激活店铺
- `missing-store-code` → 激活店铺的 Noon Store Code 没填，去 [店铺管理](./stores) 补
- 接口报错 → 看错误提示，重试

### 改了卖家状态页面没变？

按 `Cmd/⌘ + R` 刷新原页面即可；Nomu 已经把变更写到 Noon，原页面只是没自动重取。
