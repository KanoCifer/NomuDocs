# 安装 Nomu

Nomu 已上架 Chrome Web Store，整个安装过程不到一分钟。

## 安装步骤

### 1. 打开商店页面

在浏览器里访问 Nomu 的 Chrome Web Store 页面：

```
https://chromewebstore.google.com/detail/nomu/idfojgkppleknejhenmggcnnnmdglaik
```

也可以在[落地页](https://nomu.kanocifer.chat)直接点「添加到 Chrome」按钮跳转。

### 2. 点击「添加至 Chrome」

在商店页面右上角点 **添加到 Chrome**，浏览器会弹窗确认。

### 3. 确认权限并安装

确认弹窗里展示的权限后，点 **添加扩展程序** 完成安装。

### 4. 固定到工具栏（推荐）

安装完成后，点浏览器工具栏的拼图图标 🧩，把 Nomu 固定住，方便随时打开侧栏店铺面板。

## 常见问题

### 商店页打不开？

确认当前浏览器是 Chrome、Edge 或其他基于 Chromium 的内核；Firefox / Safari 不在支持范围。

### 紫鸟 / 其它 Chromium 内核浏览器怎么装？

紫鸟、跨境浏览器等基于 Chromium 的内核理论上兼容 Manifest V3 扩展加载，但 Chrome Web Store 无法直接打开。请改用以下任一方式：

1. **联系作者**获取已签名的 `.crx` 或压缩包，按浏览器官方文档「加载已解压的扩展程序」或「拖入 crx」安装。
2. 安装完成后第一次打开扩展，授权同 Chrome 上一样；店铺配置、批次草稿与登录态在每台机器独立保存，不与 Chrome 同步。

> 紫鸟浏览器的多账号窗口与 Nomu 的多店铺配置是叠加关系——同一紫鸟窗口下可登录多个 Noon 账号，每个账号再绑一个或多个 Nomu 店铺；切换紫鸟窗口即换账号上下文。

### 怎么更新到最新版？

Chrome 会自动更新已安装的扩展；也可以在 `chrome://extensions` 里打开「开发者模式」后点 **检查更新** 立即拉取。店铺设置与批次数据保存在浏览器本地，更新不会丢失。

### 图标点了没反应？

Nomu 的主界面挂在源商品页（1688 / 淘宝 / 天猫 / 京东 / noon.com）和 Noon 卖家目录页上——先登录 Noon，再打开对应页面即可看到。
