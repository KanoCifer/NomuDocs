# NomuFab 功能入口

NomuFab 是 Nomu 的主交互入口，在 Noon 卖家后台右下角以悬浮按钮形式存在。点击后升起操作菜单，采集、店铺、工具和账户入口都在里面。

## 操作方式

- 点击悬浮按钮 → 打开操作菜单。
- 点击遮罩或按 `Esc` → 关闭菜单。
- 菜单内条目支持 `↑` / `↓` 键盘导航、`Enter` 触发、`Home` / `End` 跳首尾。

## 操作菜单结构

菜单从上到下是采集、工具、账户与帮助三组功能区，最下面是你的商品分组。

## 操作项一览

### 数据与采集

| 入口 | 功能 |
| --- | --- |
| 单商品 | 打开单商品抽屉，显示待采商品列表与进度。数字角标表示待采数量。 |
| 查看 Catalog | 浏览当前店铺的商品目录，可按状态筛选、可翻页（[目录浏览](./catalog-browse)）。 |
| QuickSearch | 搜索浮层，按 Partner SKU 或标题查找商品，最多 5 条候选。快捷键 `Cmd/Ctrl + Shift + S`。 |
| 归档商品 | 查看已归档商品，支持恢复或永久删除。 |

### 商品创建与复制

| 入口 | 功能 |
| --- | --- |
| 批量复制商品 | 打开复制面板，把已有 Noon 商品复制到当前店铺，支持单个或批量。 |
| NomuDesign | 打开商品选择器，选中一个未上架商品后进入 NomuDesign 画布。 |

### 工具与系统

| 入口 | 功能 |
| --- | --- |
| 实时汇率 | 弹窗显示以 CNY 为基准的 SAR / AED 等海湾货币实时汇率。 |
| Nomu 助手 | 独立页，流式问答与商品解析。详见 [Nomu 助手](./nomu-assistant)。 |
| 连接状态 | 查看同步总线的延迟与设备。 |
| 灵动岛设置 | 隐藏或显示底部的中转站组件。 |
| 任务面板 | 独立任务页，查看全部发布任务，可筛选、重试、删除。 |
| 使用文档 | 在新标签页打开 Nomu 文档站（`https://nomu.kanocifer.chat/docs/`）。 |
| 设置 | 管理店铺、快捷键、清理本地数据等。 |
| 隐私政策 | 弹窗展示 Nomu 数据处理说明。 |

### 账户

| 入口 | 功能 |
| --- | --- |
| 账户 | 打开账户页，查看个人信息、AI 积分余额与消费流水，支持登录 / 退出。 |

## 分组

### 我的分组

显示所有已创建的商品分组，每组标注成员数量。

- 点击组行 → 进入该分组的详情视图。
- 点击右侧删除按钮 → 解组（二次确认后生效）。
- **创建分组** 按钮始终在列表底部，点击打开建组分步向导。

### 尺寸变体组

尺寸变体不在操作菜单里单独成组，它在单商品上架表单内配置（见[归组与尺寸变体组](./group-and-sizes)）。
