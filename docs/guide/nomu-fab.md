# NomuFab 功能入口

NomuFab 是 Nomu 的主交互入口，在 Noon 卖家后台右下角以悬浮按钮形式存在。点击后升起操作菜单（ActionSheet），提供商品采集、管理与工具入口。

## 操作方式

- 点击悬浮按钮 → 打开操作菜单。
- 点击遮罩或向下滑动 → 关闭菜单。
- 菜单内条目支持 ↑↓ 键盘导航、Enter 触发、Home/End 跳首尾（详见 [键盘快捷键](./shortcuts)）。

## 操作菜单结构

菜单分为三组：

| 分组       | 说明                               |
| ---------- | ---------------------------------- |
| 操作       | 核心功能快捷入口                   |
| 我的分组   | 商品分组列表 + 创建分组            |
| 尺寸变体组 | 已归组的尺寸变体（仅在存在时显示） |

## 操作项一览

### 数据与采集

| 入口         | 功能                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 单商品       | 打开单商品抽屉，显示待采商品列表与进度。数字角标表示待采数量。                 |
| 查看 Catalog | 浏览当前店铺的商品目录，支持筛选在售 / 隐藏状态。                              |
| QuickSearch  | 聚焦式搜索浮层，按 Partner SKU 或标题查找商品。快捷键 `Cmd/Ctrl + Shift + S`。 |
| 归档商品     | 查看已归档商品，支持恢复或永久删除。                                           |

### 商品创建与复制

| 入口         | 功能                                                       |
| ------------ | ---------------------------------------------------------- |
| 批量复制商品 | 打开复制面板，支持单个或批量复制现有 Noon 商品。           |
| NomuDesign   | 打开商品选择器，选中一个未上架商品后进入 NomuDesign 画布。 |

### 工具与系统

| 入口       | 功能                                                           |
| ---------- | -------------------------------------------------------------- |
| 实时汇率   | 弹窗显示以 CNY 为基准的 SAR / AED 等海湾货币实时汇率。         |
| 任务面板   | 打开独立任务页，查看全历史发布任务，支持筛选、重试、删除。     |
| 知识库助手 | 打开 RAG 智能问答面板，基于 Nomu 文档进行流式问答。            |
| 使用文档   | 在新标签页打开 Nomu 文档站（`https://kanocifer.chat/docs/`）。 |
| 设置       | 打开设置页，管理店铺、快捷键、缓存清理等。                     |
| 隐私政策   | 弹窗展示 Nomu 数据处理说明。                                   |

### 账户

| 入口 | 功能                                                               |
| ---- | ------------------------------------------------------------------ |
| 账户 | 打开账户页，查看个人信息、AI 积分余额与消费流水，支持登录 / 退出。 |

## 分组

### 我的分组

显示所有已创建的商品分组，每组标注成员数量。

- 点击组行 → 进入该分组的详情视图。
- 点击右侧删除按钮 → 解组（二次确认后生效）。
- **创建分组** 按钮始终在列表底部，点击打开建组分步向导。

### 尺寸变体组

仅在存在尺寸变体组时显示。每组显示 Partner SKU、子品数量、上架状态。

- 点击组行 → 进入该 size 组的编辑视图。
- 点击右侧删除按钮 → 溶解该 size 组（二次确认后生效）。
