# 云端配置同步

Nomu 的店铺配置（PartnerCode、店铺编码、保修设置、PSKU 前缀等）默认保存在浏览器本地。**云端配置同步**让你把这些配置备份到 Nomu 账户服务，换设备或重装扩展时一键恢复。

> 同步需要登录 Nomu 账户。同步行为**仅由你在账户页手动触发**，不会自动执行。

## 使用方式

打开「账户」扩展页（独立页 `account.html`），在「AI 积分」卡下方找到「云端配置同步」卡：

- **上传到云端** —— 把本地所有店铺配置推送到云端，覆盖云端现有备份。
- **下载到本地** —— 拿回云端全量配置覆盖本地，同时删除本地有但云端已标记删除的记录。
- **上次同步** —— 展示最近一次成功同步的本地时间；从未同步显示「从未同步」。

## 同步语义

同步以**本地为基准**：

| 操作 | 上行 | 下行 |
| --- | --- | --- |
| 上传 | 本地全量（含 version） | 服务端确认 |
| 下载 | 本地全量（满足服务端上行契约） | 云端全量 → `bulkPut` 覆盖本地 |

每次同步都传全量本地配置（最多 200 条），服务端按 `version` 做乐观并发判决（LWW：最后写为准）。远端标记 `deleted: true` 的记录会在本地执行删除。

## 数据范围

同步的字段是 Dexie `configs` 表的整行 `ConfigModel`，主要包括：

- `kind`（`store` / `global`）
- `country`、`partnerCode`、`noonStoreCode`
- `wareHouses`（FBP 仓库快照）
- `warrantyType`、`warrantyDuration`
- `pskuPrefix`、`pskuSeq`
- `fulfillmentType`、`note`
- `globalSettings`（全局设置行专用）
- `version`（乐观并发版本，每次本地改动 +1）

**不同步**商品批次、NomuDesign 草稿、任务记录——这些只留在浏览器本地。

## 存储位置

| 数据 | 位置 |
| --- | --- |
| 店铺配置 | 浏览器 `chrome.storage.local` + Dexie `configs` 表 |
| 云端备份 | Nomu 账户服务（`api.kanocifer.chat`） |
| 上次同步时间 | `globalSettings.nomuLastSyncAt`，浏览器本地 |

## 常见问题

### 换设备怎么恢复？

新设备登录同一个 Nomu 账户 → 打开账户页 → 点「下载到本地」，云端配置就会覆盖到新设备。

### 多人会冲突吗？

服务端以本地为基准 upsert，按 `version` + `updatedAt` 做 LWW 判决。后一次同步覆盖前一次；建议换设备前先做一次「上传到云端」确保最新。

### 同步失败怎么办？

失败时会 toast 提示错误信息（网络、鉴权、参数校验等），本地数据不受影响。重新点按钮即可重试。

### 不想用云端同步？

完全可以不用——不上传就不会有数据出本地。扩展的所有功能都不依赖云端同步。
