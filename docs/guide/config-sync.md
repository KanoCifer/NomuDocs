# 云端配置同步

店铺配置（伙伴代码、店铺编码、仓库、保修、PSKU 前缀与序号等）默认存在你的浏览器里。**云端配置同步**把它们备份到 Nomu 账户，换设备或重装扩展之后点一下就能恢复。

> 同步需要登录 Nomu 账户。同步只在你点按钮时发生，不会自己跑。

## 使用方式

打开「账户」扩展页，在「AI 积分」卡下方找到「云端配置同步」卡：

- **上传到云端**，把本地所有店铺配置推上去，覆盖云端现有备份
- **下载到本地**，拿云端全量配置覆盖本地，同时把云端已标记删除的记录从本地删掉
- **上次同步**，最近一次成功同步的本地时间，从没同步过就显示「从未同步」

## 同步语义

两个方向传的都是整份店铺配置，不是一段增量。同一份配置在两台设备上都改过时，以最后修改的那份为准，后一次同步覆盖前一次。换设备前先点一次「上传到云端」最稳。

## 数据范围

同步的是店铺配置：国家、伙伴代码、店铺编码、仓库、保修类型与月数、PSKU 前缀与序号、履约类型、备注，以及全局设置。

商品批次、NomuDesign 草稿、任务记录不同步，只留在你自己的浏览器里。

## 存储位置

店铺配置存在你的浏览器里，云端备份存在 Nomu 账户服务里。

## 常见问题

### 换设备怎么恢复？

新设备登录同一个 Nomu 账户，打开账户页点「下载到本地」，云端配置就盖到新设备上了。

### 多人会冲突吗？

会。以最后修改的那份为准，后一次同步覆盖前一次。在同一台设备上反复同步没问题，跨设备来回改就容易把另一边覆盖掉。

### 同步失败怎么办？

会弹一条错误提示（网络、登录过期、参数不合法都算），本地数据不受影响，再点一次按钮重试。

### 不想用云端同步？

不用也没关系，扩展所有功能都不依赖它。只是登录 Nomu 账户本身会把邮箱和令牌发给账户服务。
