# Nomu 是什么

Nomu 是面向 Noon 卖家合作平台（UAE / 沙特）的商品上架 Chrome 扩展。打开一个源商品页（1688 / 淘宝 / 天猫 / 京东 / noon.com），采集、翻译、商品图和发布在同一条流水线里走完，一路走到商品在 Noon 上架：

> 采集源商品 → 翻译（中文 → 英文 / 阿拉伯语）→ 处理成合规商品图 → 逐件发布到 Noon 完成上架（listing）

## 核心能力

- **全流程自动化**：采集、翻译、商品图、上架在一条流水线里跑完，每件商品是独立的一条任务，一件失败不影响其他件。
- **批量上架**：整批商品共享店铺设置，点一次「上架全部」逐件发布。
- **多店铺 / 多账号**：店铺配置在扩展设置里维护。只能操作当前页面登录的 Noon 店铺，暂不支持跨店铺上架。
- **合规护栏内置**：商品图在浏览器本地按 Noon 规格处理（宽 ≥ 660px、宽高比 ≥ 0.5、≤ 10MB JPEG），比例不合规时白底补边；类目、品牌、汇率换算在发布前校验。
- **归组与尺寸变体**：同品牌商品按规格轴（尺码 / 型号 / 颜色）归并成组发布，组内至少 1 件且必须同品牌，品牌不一致建不了组；父品未上架时自动先上父品。
- **任务面板**：查看所有发布任务的进度，可按状态、类型、时间筛选，失败件可单件重试或取消。
- **Nomu 助手**：面向 Noon 卖家的通用助手，问答和商品解析逐句返回，按积分计费。
- **中文界面**：工作语言为中文；夜间模式跟随系统。

## 支持的平台

| 环节     | 支持                                                |
| -------- | --------------------------------------------------- |
| 货源     | 1688、淘宝、天猫、京东、noon.com                    |
| 发布目标 | Noon 阿联酋站（`ae`）、沙特站（`sa`）               |
| 浏览器   | Chrome、Edge、紫鸟浏览器（均为 Chromium 内核，Manifest V3） |

其它货源平台在计划中，但尚未承诺上线。
