# Nomu 是什么

Nomu 是面向 Noon 卖家合作平台（UAE / Saudi）的商品上架 Chrome 扩展。它把源商品页（1688 / noon.com）的抓取、翻译、建图与发布收敛进同一条流水线，帮助卖家从「商品页」走到「Noon 已上架」：

> 抓取源商品快照 → 解析成结构化商品数据 → 翻译（中文 → 英文 / 阿拉伯语）→ 生成合规商品图 → 逐商品发布到 Noon 完成上架（listing）

## 核心能力

- **全流程自动化**：抓取、翻译、建图、上架在同一引擎内串行推进，逐商品处理，首个失败即停，可一次跑完整个批次。
- **批量上架**：一次抓取的整批商品共享店铺设置，引擎侧单商品运行，「上架全部」由界面层逐商品串行提交。
- **多店铺 / 多账号**：店铺记录按店铺独立存储；多账号运营依靠卖家浏览器中已登录的 Noon 会话，店铺配置在侧栏维护。
- **合规护栏内置**：商品图强制 660×900 JPEG、白底填充；类目、品牌、汇率换算等环节在引擎内校验。
- **尺寸变体组**：同品牌同类目商品按规格轴（尺码 / 型号 / 颜色）归并成组发布，父品未上架时自动兜底先上父品。
- **任务面板**：全历史发布任务的进度查看，支持按状态、类型、时间窗筛选，失败可单件重试或取消。
- **中文界面**：工作语言为中文；夜间模式跟随系统。

## 工作原理

Nomu 不要求额外凭证，而是与卖家日常操作共生：

1. 扩展的 Service Worker 直接向 Noon 接口发起请求，`credentials: "include"` 会自动携带卖家已登录的 Noon Cookie，不依赖打开的 Noon 页面。
2. 直连遇到网络层失败或返回 401 / 403 时，自动回退到页面主世界的 fetch 桥重发。
3. 所有请求 URL 由白名单唯一门控，白名单之外的请求一律不放行。

## 支持的平台

| 环节     | 支持                                  |
| -------- | ------------------------------------- |
| 货源     | 1688、noon.com                        |
| 发布目标 | Noon 阿联酋站（`ae`）、沙特站（`sa`） |
| 浏览器   | Chrome（Manifest V3）                 |

其它货源平台在计划中，但尚未承诺上线。
