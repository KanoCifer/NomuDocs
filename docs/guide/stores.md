# 店铺管理

Nomu 的所有上架行为都以「店铺」为粒度组织：选哪一国、合作方代码（PartnerCode）是什么、用哪个仓库、保修怎么登记、PSKU 序号怎么递增——都挂在店铺记录上。一次抓取的整批商品共享同一份店铺设置。

## 哪里看店铺

店铺管理在 Chrome 侧栏（side panel）里。两个入口：

- 工具栏点 Nomu 图标，弹出 popup → 点「打开完整侧栏」。
- 任意页面按 `Ctrl/⌘ + Shift + Y`（[键盘快捷键](./shortcuts)）。

侧栏里能看到当前激活店铺的概览（国家 / PartnerCode / 仓库数 / 保修）、店铺列表，以及「识别当前页」「新建店铺」「编辑」「刷新仓库」「删除」等动作。

## 店铺包含哪些字段

每个店铺对应 Dexie `configs` 表里的一条记录（`kind: 'store'`），结构是 `ConfigModel`：

| 字段 | 含义 |
| --- | --- |
| `note` | 备注，区分同一 PartnerCode 的多条店铺；可留空 |
| `country` | 国家：`sa`（沙特）或 `ae`（阿联酋） |
| `partnerCode` | Noon PartnerCode，新建时需为 `PRJ…` 开头或纯数字 |
| `noonStoreCode` | Noon 店铺编码（如 `STR520747-NSA`），可手动填写或一键识别 |
| `wareHouses` | FBP 仓库列表快照，发布时直接选用 |
| `warrantyType` | 保修类型（如 `seller`） |
| `warrantyDuration` | 保修时长（仅 seller 类型填写） |
| `pskuPrefix` | PSKU 前缀，默认 `N` |
| `pskuSeq` | PSKU 序号，纯数字字符串；按位宽补零递增（`0001 → 0002`），超位自然增长（`9999 → 10000`） |
| `fulfillmentType` | 履约类型：`fbp`（卖家自履约）或 `fbn`（Noon 仓） |

## 多店铺并存

同一 PartnerCode 允许多条记录并存——比如同一合作方下既有 `fbp` 又有 `fbn` 仓库，或者 UAE / Saudi 各一条。新建永远追加；备注撞名由存储层自动追加 `-1`、`-2` 等后缀。

切店铺只改「当前激活」指针；商品批次、NomuDesign 草稿、任务记录互不打扰。

## 一键识别当前页

打开 noon-catalog 的卖家后台（如 `https://catalog.noon.partners/...`），侧栏顶部「**识别当前页**」会从当前标签页的 URL 与 merchant API（`noon-store/list`）里解析店铺信息并写入店铺记录。这一步会：

1. 抓取 `noonStoreCode` 编码。
2. 反查合作方、当前国家等元数据。
3. 自动保存到店铺记录，并提示「已识别并保存 {partnerCode}」。

> 旧版用过 `cookies` 权限读 `noonStore` cookie 推断店铺，已迁移到 merchant API，权限面更小。

## FBP 仓库快照

编辑或识别店铺时会 best-effort 拉一次 FBP 仓库列表，落进 `wareHouses`。如果当时网络抖动拉取失败，旧的快照会保留，事后可在店铺列表行点「刷新」按钮重试。

发布时，店铺关联的仓库列表直接进入上架流水线的「库存」步骤，不需要每件商品都重新选仓库。

## PSKU 序号

PSKU 序号是**纯数字字符串**，位宽由字符串长度决定：

- 默认 `1` → 实际写入为 `1`、`2`、`3` …
- 若希望保持 `0001` / `0002` 这样的宽度，把序号存成 `"0001"` 即可
- 超位自然增长：存了 `9999` 之后就变 `10000`

发布引擎按店铺当前 `pskuSeq` 累加，写完后回写到店铺记录；同一店铺内不自相打架。

## 履约类型

- `fbp`（Fulfilled by Partner）—— 卖家自履约，自己出仓。
- `fbn`（Fulfilled by Noon）—— 入 Noon 仓，由 Noon 配送；店铺记录里会单独维护仓库。

不同履约类型走的发布链路不同，店铺记录里挑错会导致「库存」步骤失败。

## 删除与归档

删除店铺会一并清掉它名下的 PSKU 序号等元数据，但**不会**回滚已经发布到 Noon 的商品——Noon 上架是单向动作，删除店铺前请确认没有依赖该店铺的批次或任务。

如果只是暂时不用，建议保留记录、改备注区分；多店铺并存是常态。

## 常见问题

### 怎么知道当前激活的是哪家店铺？

popup 顶部 hero 直接显示当前店铺的「备注 / PartnerCode / 国家」；侧栏里激活项会用高亮 + 圆点标出。

### 同一 PartnerCode 想分两条店铺怎么做？

直接「新建店铺」填同一个 PartnerCode、不同备注或不同国家即可。两条会同时存在，互不影响。

### 改店铺配置会不会影响历史任务？

任务记录里记的是发布当时的店铺快照视图（`ListingStoreTarget`），改店铺不会回写历史任务。

### 没看到「识别当前页」按钮？

确认当前打开的是 noon-catalog 后台标签页；如果当前 tab 不是 noon 域，会提示「未检测到当前标签页 URL」。
