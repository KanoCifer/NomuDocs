# 快捷搜索

快捷搜索是浮在 Noon 卖家后台上方的一块搜索面板：按 `Ctrl/⌘ + Shift + S`，输入 SKU 或标题，当前店铺下的在售 / 隐藏商品立刻排出来，回车跳详情，按 `Shift + Enter` 改状态。不用先翻列表再找。

## 打开方式

- 快捷键 `Ctrl/⌘ + Shift + S`（[键盘快捷键](./shortcuts)）
- 操作菜单里的「QuickSearch」入口

打开后输入框已经是聚焦状态，直接打字就行。

## 视觉与展示

每条候选展示：标题、你的 Partner SKU、价格、状态（在售 / 隐藏）。

- 最多 5 条候选，关键词越具体越准
- 底部告诉你当前状态：还有几条候选、正在搜、没匹配上，还是搜索失败
- 没选店铺时提示先去设置页「店铺管理」里选一个
- 没搜到时会把你搜的那个词显示出来，让你换个词再试

## 键盘操作

| 键 | 行为 |
| --- | --- |
| `↓` / `Ctrl + N` | 选中下一条 |
| `↑` / `Ctrl + P` | 选中上一条 |
| `Enter` | 打开当前选中的详情（新标签页） |
| `Shift + Enter` | 切换当前选中的卖家状态（在售 ↔ 隐藏） |
| `Esc` | 关闭浮层 |

文本输入时上下键不会触发选中切换，避免与文字编辑冲突。

## 行内动作

每条候选除了回车跳详情，还能：

- **切状态**（`Shift + Enter`），结果直接写回 Noon
- **铅笔按钮 → 编辑商品**，改商品内容、价格、条码等

## 与商品目录的关系

快捷搜索是 [商品目录](./catalog-browse) 的聚焦版，同样的状态切换和编辑弹窗。区别在于：

| 维度 | 快捷搜索 | 商品目录 |
| --- | --- | --- |
| 入口 | 快捷键 | 操作菜单「查看 Catalog」或扩展弹窗 |
| 形态 | 顶部居中的浮层，键入即用 | 独立扩展页，列表 / 详情 / 筛选三栏 |
| 候选量 | 最多 5 条 | 每页 50 条，可翻页 |
| 适用场景 | 快速定位、改状态 | 系统性浏览一批商品，并查费用构成与利润 |

## 常见问题

### 按快捷键没反应？

- 确认当前在 Noon 卖家后台页面
- 确认 Chrome 是当前聚焦窗口
- 看 `chrome://extensions/shortcuts`，快捷键可能被改成「未分配」，或被别的扩展抢走了

### 改了状态原 Noon 页面没动？

按 `Cmd/⌘ + R` 刷新原 Noon 后台页面。Nomu 已经把变更写到 Noon，原页面只是没自动刷新。
