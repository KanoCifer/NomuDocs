# 快速上手

三步走完一批货：采集 → 确认 → 发布。

## 1. 在源商品页一键采集

打开任意 1688 或 noon.com 商品详情页，扩展会自动把商品信息（标题、图集、规格变体、价格）加入待发布列表。1688 的「一父多变体」会被拆成多个互相独立的商品，每个商品自带完整内容，互不依赖。

## 2. 逐条确认

在 Noon 卖家目录页打开上架抽屉，逐条核对商品：

- 调整价格、币种（内置人民币汇率换算）
- 检查自动翻译的英文 / 阿拉伯语标题与卖点
- 商品图已自动处理为 Noon 要求的 660×900 JPEG 白底
- Noon 类目已根据源数据自动推荐，可手动修改
- 选择店铺配置（国家、合作方代码、仓库、数量、质保、品牌）

## 3. 逐件发布到 Noon

提交后引擎按固定链路走完每个商品：创建商品 → 上传图片 → 写入属性（英 / 阿）→ 设置价格 → 库存 → 条码（可选）→ 激活 → 保修登记（可选）。

- **失败即停**：批次中第一件失败就停止整个批次，不会出现一半上架、一半漏掉的情况。
- **续跑**：重试时已成功的步骤自动跳过。
- **进度可查**：任务面板展示全历史任务状态，失败件可单独重试或取消。

## 多店铺与多账号

在侧栏维护多家店铺配置；多账号切换依靠按标签保存 / 恢复你浏览器里已登录的 Noon 会话。店铺编码可从当前页面自动识别（通过 Noon Catalog 的店铺列表 API）。

## 常见问题

### Nomu 是免费的吗？

工具本身免费使用。设置与登录信息都留在你自己的浏览器里，没有订阅费。

### 需要提供密钥或登录授权吗？

不需要。Nomu 通过你已登录的 Noon 会话直接操作，不用输入密码或密钥。

### 翻译质量如何？是否需要二次校对？

翻译自动完成（中译英 / 阿）。高客单价或品牌商品建议发布前人工抽检，自动翻译不保证等同于母语水平。

### 上架失败的商品会怎样？

批量发布中第一件失败即停止；失败的商品会在列表中标出，可单独重试或手动修改后再发布。
