# 快速上手

走完一批货：登录 → 采集 → 确认 → 发布。

## 0. 安装并登录 Nomu 账户

按[安装页](./install)选一条路径装上：Chrome Web Store，或者紫鸟浏览器插件中心（可按店铺环境分配）。

打开扩展的「账户」页，用邮箱验证码或邮件链接登录，两种方式都不用密码。AI 翻译、NomuDesign 生图与提示词优化在此基础上另按积分计费。详见[账户与 AI 积分](/guide/account)。

## 1. 在源商品页一键采集

打开任意 1688、淘宝、天猫、京东或 noon.com 商品详情页，扩展会自动把商品信息（标题、图集、规格变体、价格）加入待发布列表。

## 2. 逐条确认

在 Noon 卖家目录页打开上架抽屉，逐条核对商品：

- 调整价格、币种（内置人民币汇率换算）
- 检查自动翻译的英文 / 阿拉伯语标题与卖点
- 商品图已自动处理成 Noon 规格（宽 ≥ 660px、宽高比 ≥ 0.5、≤ 10MB JPEG）
- Noon 类目已根据源数据自动推荐，可手动修改
- 选择店铺配置（国家、PartnerCode、仓库、数量、质保、品牌）

## 3. 逐件发布到 Noon

提交后每个商品按同一条链路发布：创建商品 → 上传图片 → 写入属性（英 / 阿）→ 设置价格 → 库存 → 条码（可选）→ 激活 → 保修登记（可选）。

- **每件一个任务**：批次里一件失败不影响其他件，队列继续往下走。
- **重试不重跑**：重试时已成功的步骤自动跳过。
- **进度可查**：任务面板展示全部任务的状态，失败件可单独重试或取消。

## 顺手做的事

- **导出待发布清单为 Excel**：采集抽屉顶部「导出」一键把当前清单生成 `.xlsx`，包含源 URL、标题、SKU、参考价格，可发给同事对账，或在表格里改完字段再回填。
- **推到中转站**：同一抽屉的「推送到中转站」把当前清单送上账号云端池（详见 [云端共享池与中转站](./cloud-pool)），本机不落库，等另一台设备领取。

## 多店铺与多账号

在扩展设置里维护多家店铺配置；多账号切换靠保存 / 恢复你浏览器里已登录的 Noon 会话。店铺编码可从当前页面自动识别。

暂不支持跨店铺上架，只能操作当前页面登录的 Noon 店铺。

## 常见问题

### Nomu 是免费的吗？

扩展本体免费使用，不按功能收费。AI 翻译、生图与助手按积分计费；设置与登录信息都留在你自己的浏览器里。

### 需要提供密钥或登录授权吗？

面向 Noon 不需要。Nomu 通过你已登录的 Noon 会话直接操作，不用输入 Noon 密码或密钥。

### 需要注册 Nomu 账户吗？

需要。注册在官网完成，登录在扩展账户页用邮箱验证码或邮件链接。未登录时功能页会显示登录墙。详见[账户与 AI 积分](/guide/account)。

### 翻译质量如何？是否需要二次校对？

翻译自动完成（中译英 / 阿）。高客单价或品牌商品建议发布前人工抽检，自动翻译不保证等同于母语水平。

### 上架失败的商品会怎样？

失败的商品会在任务面板里标出，暂停后续步骤，可以改完再单独重试，已成功的步骤不会重跑。
