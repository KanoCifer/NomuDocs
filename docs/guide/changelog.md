## 0.12.0beta

_2026-08-26 · 公测初始版本_

Nomu 首个公开发布的版本，完整覆盖从 1688 采集到 Noon 上架的核心流水线。

### 核心功能

- **1688 / Noon 商品采集**：在 1688 或 noon.com 源商品页一键抓取标题、图集、规格变体与价格，解析成结构化的待发布清单。
- **上架流水线**：声明式步骤引擎驱动单商品走完创建、属性、图片、价格、库存、条码、激活、保修的完整链路；首个失败即停，重试自动跳过已成功步骤。
- **多语言翻译**：中文 → 英文 / 阿拉伯语，标题与卖点自动翻译，覆盖阿联酋与沙特两站。
- **合规图片处理**：商品图自动转换为 660×900 JPEG 白底填充，不因图片规格被拒。
- **尺寸变体组**：同品牌同类目商品按尺码轴归并成组发布，父品未上架时自动兜底先上父品。
- **多店铺管理**：侧栏维护多家店铺配置，按标签保存 / 切换登录会话，店铺编码可从当前页自动识别。
- **任务面板**：全历史发布任务进度查看，支持状态 / 类型 / 时间窗筛选，失败件可单独重试或取消。
- **类目推荐**：根据采集数据自动推荐 Noon 类目（AI 预测 + 官方类目表），支持手动指定。
- **汇率换算**：内置人民币汇率查询，定价时直接换算 AED / SAR。

### 说明

- 公测期间免费使用，设置与数据全部保存在本地浏览器。
- 安装方式见[安装 Nomu](/guide/install)。
