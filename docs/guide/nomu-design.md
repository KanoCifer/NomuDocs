# NomuDesign 商品图生图

NomuDesign 是 Nomu 自带的 AI 商品图生图工作台。它不是「一键换背景」滤镜，而是一张可编排的画布：你把商品原图、参考图、提示词、生图节点拼起来，AI 按提示词生成新图，再一键写回商品图集。

> 需要登录 Nomu 账户才能跑图——[账户与积分](./account) 里的 AI 积分会被消耗。

## 进入方式

三个入口都跳到独立扩展页 `nomu-design.html?productId=...`：

- 单商品抽屉 / 分组页的「去 NomuDesign」入口
- 操作菜单（Action Sheet）里的「NomuDesign」入口，弹出商品选择器
- 应用结果后自动跳回画布

画布与商品一一对应：一商品一草稿，刷新后不丢。

## 画布的四种节点

| 节点 | 作用 |
| --- | --- |
| 商品图（image） | 从商品图集挑出来的图，作为原图或最终应用目标 |
| 参考图（referenceImage） | 上传一张参考图，给提示词做视觉指引 |
| 提示词（prompt） | 写给 AI 的提示词；可一键「AI 优化」改写 |
| 生图（generation） | 跑图节点；带模型 + 档位 + 状态 + 生成结果 |

节点可以连成你想要的链路：参考图 → 提示词 → 生图，节点按拓扑决定哪些上下文喂给 AI。

## 模型与档位

生图节点右上角的下拉切换 `model · tier`：

- **Doubao-Seedream-5.0-lite**：档位 2K / 3K / 4K
- **Doubao-Seedream-5.0-pro**：档位 1K / 1.5K / 2K

切换模型时如果旧档位不在新模型的档位列表内，会自动回落到新模型的首档，避免出现非法值。

## 提示词模板与 AI 优化

提示词节点自带三件套：

- **预设模板** —— 内置的常用提示词清单，一键插入
- **模板列表 / 下拉** —— 你保存过的模板集合
- **「存为模板」** —— 把当前提示词保存成自建模板（带分类），下次再套
- **AI 优化** —— 一键调 AI 改写 / 增强提示词（消耗积分）

提示词输入框 10 行高度，便于长提示词编辑。

## 生成图与历史

每个生图节点保留**最近 5 张**生成结果（`GENERATION_HISTORY_LIMIT`）。可以：

- 缩略图回看每一版
- 点击切回旧版本（切回只是替换当前 `designRef` 指针，不维护双向历史）
- 单图下载
- 画布级 Lightbox 翻页查看

重复生成对节点是**覆盖**语义——节点只持当前稿；被替换的旧行**仅在仍被下游链式节点 `designRef` 钉住时**保留，防止悬空引用。

## 应用到商品

生图完成后点「应用到商品…」：

- **复制**语义——新起 `${memberId}-image-${sort}` 的 `productAssets` 行 + 商品 `images` 追加短引用，与生成图原件互不依附
- **跨成员复用**——应用目标可以是画布归属商品，也可以是同组任意成员，组内多件商品共用一张设计稿
- 商品主图已达上限（9 张）时会提示，不再追加

应用后会弹窗确认目标列表；选完点应用，写入商品图集并自动跳回画布。

## 数据持久化

- 画布以**草稿**形式持久化到 Dexie `workbenchDrafts`（一商品一草稿）
- 生成图字节落 `designAssets`（独立领域对象，自带 lineage：提示词、模型、档位、参考图引用）
- 商品图字节落 `productAssets`（v10 从行内 base64 拆出），主图行上只存 `asset:<id>` 短引用
- 草稿、生成图、商品图三张表互不污染，删除语义天然解耦

> 商品归档（`status='archived'`，可 unarchive）不删 designAssets——恢复后工作台草稿仍完整。

## 与上架流水线的关系

NomuDesign 不参与上架步骤表。它是「上架前」的准备动作：生完图、应用到商品后，再走常规上架流水线，图片步骤直接使用新的商品图。

## 常见问题

### 跑图失败 / 余额不足？

账户页（[账户与积分](./account)）的积分卡会显示余额；余额不足或服务不可用会明确提示。

### AI 优化会重复扣费吗？

AI 请求带幂等键——超时重试不会重复扣费。

### 应用后会替换原图吗？

不会。应用是「追加主图到商品图集」语义，原图不动；想换主图顺序去商品编辑里点「设为主图」。

### 草稿丢了？

草稿按商品 ID 落库，重开画布自动恢复；如果商品已归档，NomuDesign 仍能进入浏览，草稿完整可继续编辑。
