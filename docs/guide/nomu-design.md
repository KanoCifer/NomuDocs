# NomuDesign 商品图生图

NomuDesign 是 Nomu 自带的 AI 商品图生图工作台。它不是「一键换背景」滤镜，而是一张可编排的画布：你把商品原图、参考图、提示词、生图节点拼起来，AI 按提示词生成新图，再一键写回商品图集。

> 未登录时整个设计工作台被登录墙替换；登录后才能跑图，会消耗 [账户与积分](./account) 里的 AI 积分。

## 进入方式

三个入口都跳到同一个设计页：

- 单商品抽屉 / 分组页的「去 NomuDesign」入口
- 操作菜单（Action Sheet）里的「NomuDesign」入口，弹出商品选择器
- 应用结果后自动跳回画布

画布与商品一一对应：一商品一草稿，刷新后不丢。

## 画布的四种节点

| 节点 | 作用 |
| --- | --- |
| 商品图 | 从商品图集挑出来的图，作为原图或最终应用目标 |
| 参考图 | 上传一张参考图，给提示词做视觉指引 |
| 提示词 | 写给 AI 的提示词；可一键「AI 优化」改写 |
| 生图 | 跑图节点；带模型 + 档位 + 状态 + 生成结果 |

节点可以连成你想要的链路：参考图 → 提示词 → 生图，连起来的顺序决定哪些内容喂给 AI。

## 模型与档位

生图节点右上角的下拉切换模型和档位：

- **Doubao-Seedream-5.0-lite**：档位 2K / 3K / 4K
- **Doubao-Seedream-5.0-pro**：档位 1K / 1.5K / 2K

换模型时如果原来的档位在新模型里没有，会自动落到新模型的第一档。

## 提示词模板与 AI 优化

提示词节点自带这些工具：

- **预设模板**：内置的常用提示词清单，一键插入
- **模板列表 / 下拉**：你保存过的模板集合
- **「存为模板」**：把当前提示词保存成自建模板（带分类），下次再套
- **AI 优化**：一键调 AI 改写 / 增强提示词，消耗积分

## 生成图与历史

每个生图节点保留**最近 5 张**生成结果，可以：

- 缩略图回看每一版
- 点击切回旧版本
- 单图下载
- 画布级 Lightbox 翻页查看

同一个节点再跑一次，新结果覆盖旧结果，节点上只留当前这一版。还没被下游节点用到的旧图会被清掉。

## 应用到商品

生图完成后点「应用到商品…」：

- 应用是**追加**语义，新图写进商品图集，和生成时的原件互不依附
- 应用目标可以是画布归属的商品，也可以是同组任意成员，组内多件商品能共用一张设计稿
- 商品主图已达上限（9 张）时会提示，不再追加

应用后会弹窗确认目标列表；选完点应用，写入商品图集并自动跳回画布。

## 与上架流水线的关系

NomuDesign 不参与上架步骤表。它是「上架前」的准备动作：生完图、应用到商品后，再走常规上架流水线，图片步骤直接使用新的商品图。

## 常见问题

### 跑图失败 / 余额不足？

账户页（[账户与积分](./account)）的积分卡会显示余额；余额不足或服务不可用会明确提示。

### AI 优化会重复扣费吗？

不会。同一次操作超时重试也只扣一次积分。

### 应用后会替换原图吗？

不会。应用是「追加主图到商品图集」语义，原图不动；想换主图顺序去商品编辑里点「设为主图」。

### 草稿丢了？

草稿按商品保存，重开画布自动恢复；如果商品已归档，NomuDesign 仍能进入浏览，草稿完整可继续编辑。
