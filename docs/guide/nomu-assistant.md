# Nomu 助手

Nomu 助手是一个面向 Noon 卖家的通用助手。你用日常中文把问题说出来，它逐字把答案打出来；遇到要动手的事（比如解析一个商品），它会自己去调工具。

它开在单独一页里，两栏布局：左边是会话侧栏，右边是对话区。

## 打开方式

- 扩展弹窗 →「Nomu 助手」
- Noon 卖家后台的操作菜单 →「Nomu 助手」（副标题：问答与商品解析）

两条入口走的是同一个页面，已经打开过就直接切过去，不会开出第二个标签页。

## 能做什么

空会话时给三条示例问题，点一下就填进输入框：

- 为什么把 SKU 模板从硬编码改成品牌字段？
- Currency 的拉取间隔是多少
- 解析一下这个商品

日常用法大致两类：**问**（上架规则、字段含义、报错怎么办）和**让它做**（解析商品、查数据、批量打条码标签）。具体某类问题能不能直接给出答案，以当次回答为准。

助手要动手做事时，气泡里会亮起一个工具调用圆片，做到哪一步就在哪一步显示「执行中」和「已完成」。

其中批量条码标签的完整说明在[条码标签打印](./barcode-labels#在助手里生成)，支持的规格、重复项怎么算、单次能出多少张都在那里。

## 回答怎么读

| 现象 | 说明 |
| --- | --- |
| 字逐个出现 | 回答是边生成边显示的，长回答不用干等 |
| 「正在生成」 | 这一轮还没写完；此时可以点「停止」打断 |
| 「回到最新」 | 回答变长时右下角出现，点一下回到正在生成的位置 |
| 工具调用圆片 | 助手在做事，显示「执行中」到「已完成」 |
| 顶栏右侧 | 助手当前的连接状态 |

Markdown 与代码块在生成过程中就能跟着读，中文标点和行内样式按中文习惯处理，不会断行错位。

> 回答由 Nomu 助手生成，请注意辨别。

## 会话

侧栏管三件事：

- **开启新会话**：开一条干净的上下文接着问
- **最近对话**：按最后活动时间排序，标题取这条会话的第一句提问
- **删除会话**：悬停会话行时浮出删除键

## 登录

助手需要登录 Nomu 账户才能用。未登录时整个助手页会被登录墙替换，去[账户页](./account)登录后回来即可继续。

登录后，侧栏和消息气泡的头像显示的是你自己的用户名。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Enter` | 发送 |
| `⇧ Enter` | 换行 |

## 与「用 AI 解析」右键菜单的区别

两个入口名字都带 AI，但做的事完全不同：

| 维度 | Nomu 助手 | 右键「用 AI 解析」 |
| --- | --- | --- |
| 触发 | 弹窗 / 操作菜单点开 | 任意页面右键菜单 |
| 做什么 | 对话式问答与代办，含商品解析 | 把当前页解析成可上架的商品草稿 |
| 产物 | 逐字返回的回答 | 落到本地批次（或中转站）的商品草稿 |
| 适合 | 问规则、查字段、问报错 | 遇到没适配器的页面，临时要一份草稿 |

右键解析适合「这个站点没适配器，但我想先拿到一份草稿」；助手适合你正在做事、想顺口问一句的时候。
