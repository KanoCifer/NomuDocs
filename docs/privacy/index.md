# 隐私政策

最后更新：2026-10-02

替你干活的工具，不该让你盲目信任。本文说明 Nomu 处理哪些数据、数据去了哪里、我们永远不会看到什么。

## 一句话总结

**店铺设置与批次草稿默认留在本地 · 没有埋点与追踪 · 采集支持 1688 / 淘宝 / 天猫 / 京东 · 云端只有五类 AI 调用，转交第三方模型服务商执行，上行内容逐类写明 · 右键解析的成品保存到服务端，但仅限你自己账户下的其他设备可取用。**

## Nomu 账户

Nomu 扩展的各功能页、采集抽屉与悬浮按钮都需要登录 Nomu 账户才能使用。注册与登录的方式如下：

- **注册**在官网（`nomu.kanocifer.chat/register`）完成，需要用户名、邮箱、邮箱验证码与密码；**登录**在扩展账户页完成，支持邮箱验证码与邮件链接（点邮件里的链接即可确认登录）两种方式，都不用密码。
- 密码只在官网的注册页与密码重置页经 HTTPS 提交给账户服务（`api.kanocifer.chat`）用于校验，扩展内既不收集也不存储你的密码。
- 登录后，访问令牌与刷新令牌保存在你浏览器的本地存储中，仅用于向 Nomu 服务表明身份；登出即从本地清除。
- 账户是**多设备**模型：同一账户最多可在 5 台设备上保持登录，新设备登录不会使旧设备的会话失效；每台设备登出只清除该设备自己的会话。
- Nomu 账户与你的 Noon 登录完全独立：登录 Nomu 不读取、不影响你的 Noon 会话。
- 未登录时，扩展的功能页会显示登录引导，采集抽屉的表单与提交按钮同样需要登录后才能使用。**宿主商品页（1688 / 淘宝 / 天猫 / 京东 / noon.com）本身不受影响**，登录前你仍可正常浏览和查看商品，只是 Nomu 在页面上提供的采集与操作功能需要先登录。

## 数据去向一览

### 留在本地（你的浏览器里）

以下数据只保存在你浏览器的本地存储中，不上传到任何服务器：

- 你的店铺设置（国家、合作方代码、仓库、数量、质保、品牌）
- 你的店铺记录与当前使用的店铺
- 你的商品批次草稿
- Nomu 账户的登录令牌
- NomuDesign 草稿（提示词、参考图、生成历史与画布编辑状态）

商品图片的白底规格处理也在你的浏览器本地完成，不经服务端中转。

### 只发给 Noon（你提交的内容）

以下数据在你主动提交上架时，经由你已登录的 Noon 会话发送给 Noon 平台：

- 商品信息（标题、描述、属性、价格、库存）
- 商品图片（已本地处理为白底 JPEG：宽度 ≥ 660px、宽高比 ≥ 0.5、单张 ≤ 10MB）
- 质保与激活请求

这些请求与你在 Noon 卖家后台手动操作产生的请求相同，Nomu 只是替你执行。

### 发给账户服务（登录 / 注册时）

登录与注册时，以下信息经 HTTPS 提交给 Nomu 账户服务（`api.kanocifer.chat`）：

- 用户名与密码（官网注册 / 重置密码时，由 `nomu.kanocifer.chat` 网页提交）
- 邮箱与邮箱验证码（注册、验证码登录、邮件链接登录与重置密码时）

### Nomu AI 服务（需登录）

以下五类调用由 Nomu 的云端服务受理后，**转交第三方模型服务商执行**（逐类对应关系见下文「第三方模型服务商」）。请求携带你的账户访问令牌用于身份鉴权与积分扣减，**令牌只发给 Nomu 云端，不会转发给模型服务商**。**上行内容逐类列明，其中第 4、5 类请重点留意：**

- **翻译**：上行携带待翻译的商品文本（标题、描述），下行返回翻译结果。
- **提示词优化**：上行携带提示词文本，下行返回改写后的提示词。
- **生图**：上行携带提示词、（可选）参考图 base64 与生成参数（模型、尺寸档位），下行返回生成图片的媒体地址（`api.kanocifer.chat/v3/media/design/*`）。**参考图仅用于本次生成，不在账户服务侧留存。**
- **商品解析**（`v2/nomu/product-parse`）：由页面右键菜单「AI 解析商品草稿」触发，是**上行内容最重的一类**。上行携带你右键所处页面的：页面 URL、标题、描述、价格与币种、JSON-LD 结构化数据（最多 5 条）、主图（最多 20 张）、页面图片（最多 40 张）、**页面正文纯文本**，以及**当前视口的整屏截图**（裸 base64 JPEG）。解析为异步任务，下行先返回任务号。
- **助手问答**（`v2/knowledge/ask`）：详见下文「Nomu 助手」一节。

前三类调用除鉴权与计费必需外，请求不携带你的店铺配置、批次草稿或其他本地数据。**商品解析与助手问答按设计必须携带你主动提供的内容**——分别是右键所处页面的正文与视口截图、以及你的提问。

### 第三方模型服务商

Nomu 云端不自行训练模型。五类 AI 调用按类型转交下列第三方服务商执行。**你的账户令牌、店铺配置、批次草稿与登录信息都不会发送给它们**：

| 调用类型           | 服务商                                    | 发送给服务商的内容                                                                                            | 返回给你                                                                 |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 翻译               | DeepSeek                                  | 待翻译的商品标题与描述                                                                                        | 译文                                                                     |
| 提示词优化         | DeepSeek                                  | 提示词文本                                                                                                    | 改写后的提示词                                                           |
| 助手问答           | DeepSeek                                  | 你的提问，以及该会话的对话上下文                                                                              | 流式回答                                                                 |
| 商品解析           | DeepSeek                                  | 页面 URL、标题、描述、价格与币种、JSON-LD（≤5 条）、主图（≤20 张）、页面图片（≤40 张）、**页面正文纯文本**、**当前视口整屏截图（base64 JPEG）** | 解析出的商品草稿（另写入你自己的云端池） |
| 生图 `Doubao-*`    | 火山引擎方舟（豆包 Seedream 5.0 / 5.0-pro） | 生图提示词、（可选）参考图（URL 或 base64）、尺寸档位                                                        | 生成图，落盘到 Nomu 媒体存储                                             |
| 生图 `gpt-image-*` | apiyi                                     | 生图提示词、（可选）参考图（multipart 上传）                                                                  | 生成图，落盘到 Nomu 媒体存储                                             |

关于生图的几点：

- **按模型自动路由**：你在 NomuDesign 选哪个模型，就走哪一家——`Doubao-*` 走方舟，`gpt-image-*` 走 apiyi。两家密钥彼此独立，可同时使用。
- **参考图**：仅用于本次生成。**我们自己的服务器不留存**参考图；但它会随请求发送给上表对应的生图服务商，由其执行生成。
- **结果图立即转存**：上游返回的图片地址是临时链接（apiyi 约 24 小时过期），云端收到后会立即转存到 Nomu 自己的媒体存储（`api.kanocifer.chat/v3/media/design/*`），只把这个本站地址交回扩展。

**上游留存与训练策略**：我们不掌握第三方服务商内部的日志留存与训练使用策略，也无法代其承诺。模型服务商的条款可能随时调整。涉及敏感内容的入口（商品正文、视口截图、助手提问、参考图）请先自行评估，各服务商的条款以其官方公布的隐私政策与用户协议为准。

### AI 积分与消费流水（账户侧持久化）

账户服务按上述五类调用扣减积分，并在服务端持久化：

- 积分余额（按分计，100 分 = 1 元，积分不过期）
- 每笔消费流水（来源 / 时间 / 消耗分值），来源枚举：`translate`（通用翻译）、`nomu_prompt_optimize`（提示词优化）、`design_generate`（生图），以及商品解析与助手问答各自独立的一类来源（具体枚举值以账户服务返回为准）

积分数据在账户页内可见、可手动刷新。删除 Nomu 账户与对应积分数据可通过邮件联系作者（见文末）。

### 汇率服务

上架时由插件向汇率服务发起请求以换算本地币种价格；请求仅携带汇率查询参数，不携带商品或店铺数据。

### 云端配置同步（需登录，手动触发）

账户页提供「上传到云端」与「下载到本地」两个手动按钮，触发后店铺配置（partnerCode、店铺编码、备注、保修设置、PSKU 前缀等）经账户服务（`api.kanocifer.chat`）同步。**仅由你在账户页手动触发，不会自动执行。** 上次同步时间保存在浏览器本地，在账户页展示。

### 云端池（需登录）

右键「AI 解析商品草稿」解析成功后，生成的商品草稿会经账户服务（`api.kanocifer.chat`）保存到服务端，供**你自己账户下的其他设备**取用。行为如下：

- 传输通道是**按账户鉴权**的同步连接（`v3/nomu/sync/ws`，连接时即携带你的账户令牌）。因此池中内容**只对你本人可见，其他 Nomu 账户无法访问**。
- 扩展启动时会拉取池中全量条目；池内有新条目时，服务器向**你账户下的在线设备**广播增量。
- 每条快照带有**写入方的设备标识 `device_id` 与设备名**，用于让你分辨是哪台设备写入的。
- 你在某台设备上「领取」某条快照后，该条目对同账户的其余设备移除（独占摘取）。

请注意：商品草稿会**离开本机、保存到发布方的服务器**，以支持你自己的多设备取用。请不要在含有敏感信息的页面上使用右键解析。池中数据可由你本人在扩展内领取或删除；需要清空全部历史，请邮件联系作者（见文末）。

### Nomu 助手（需登录）

Nomu 助手是一个基于服务端知识库的问答助手。上行与存储行为如下：

- **提问**：`v2/knowledge/ask`。上行携带你的提问文本与账户访问令牌，以 SSE 流式返回回答。
- **会话正文保存在服务端**：本地只保存会话的 **id、标题与最近使用时间**（一份"地址簿"），**对话正文由服务端保存**，扩展按 `session_id` 从服务端回读并显示。
- **知识库状态**：`v2/knowledge/status` 读取知识库入库进度；`v2/knowledge/ingest` 触发一次增量入库。知识库内容由作者维护，不由你的数据构建。
- 助手会消耗积分；未登录或积分耗尽时不发起请求。

请注意：你的提问会离开本机，**发送给 DeepSeek 执行，并由服务端持久化**。**不要在助手里提交敏感信息。** 需要删除某个会话，请邮件联系作者（见文末）。

## 我们永远不会看到

- 你的 Noon 账号密码
- 面向 Noon 的任何密钥或 OAuth 授权
- 任何追踪、统计、埋点数据
- 你的浏览历史或不相关网站的 Cookie
- NomuDesign 的参考图（我们自己的服务器不留存；仅随生图请求提交给当次使用的生图服务商执行生成）

## 需要你知道的例外

下面几项**会**离开你的设备并存到服务端，这里集中列出，避免遗漏：

| 数据                                        | 存到哪                        | 谁能看到                        |
| ------------------------------------------- | ----------------------------- | ------------------------------- |
| 右键采集的页面正文与当前视口整屏截图        | Nomu AI 服务（商品解析）      | 解析处理过程                    |
| 右键解析生成的商品草稿 + 写入设备 `device_id` 与设备名 | 云端池         | **仅你自己账户下的其他设备**    |
| 助手的提问与回答                            | Nomu 助手服务                 | 服务端持久化，按 `session_id` 回读                |
| 上述五类 AI 调用的上行内容                  | 第三方模型服务商              | 仅执行当次推理，见「第三方模型服务商」            |
| 邮箱、邮箱验证码、账户访问令牌              | 账户服务                      | 账户鉴权与计费必需；不转发给模型服务商            |

以上数据均**不与第三方共享**；服务端为发布方自有的账户服务，访问受账户令牌隔离。唯一的内容外发是上表第二行：**为完成你主动发起的 AI 调用，当次输入会提交给对应的模型服务商执行**，详见「第三方模型服务商」一节。

## 权限说明

Nomu 申请以下 Chrome 权限：

| 权限     | 用途                                                   |
| -------- | ------------------------------------------------------ |
| 本地存储 | 把你的店铺记录、设置、批次草稿与登录令牌保存在浏览器里 |
| 定时器   | 在后台按计划处理你的上架任务队列                       |
| 通知     | 解析任务回执与云端池任务入队时弹出合并提醒（多条合并为一条），点击通知打开对应面板 |
| 右键菜单 | 在网页右键菜单提供「AI 解析商品草稿」，用于从你自己的独立站 / 品牌官网采集商品。点击菜单项即构成一次主动授权 |
| 按需授权（activeTab） | 仅在你主动发起「当前页采集」或点击右键菜单项时临时访问当前标签页，不预授权任何网站 |
| 脚本注入（scripting） | 配合按需授权，在你发起采集的标签页内注入采集脚本，读取页面商品信息 |

不申请 `cookies`、`tabs` 等敏感权限：插件不读取浏览器 Cookie。除获授权网站外，插件平时不访问其他标签页；仅当你主动发起「当前页采集」或点击右键菜单「AI 解析商品草稿」时，才按 activeTab 机制临时访问当前标签页（浏览器内部页与 Chrome 应用商店始终排除），离开该标签页授权即失效。

> 右键菜单项在任意 `http` / `https` 页面都会出现，这是为了覆盖你自己的独立站与品牌官网。请留意其后果：点击它会把当前页面的正文与视口整屏截图提交给 Nomu AI 服务做解析，解析成品保存到服务端供你自己账户下的其他设备取用（见上文）。
