# 隐私政策

最后更新：2026-08-28

替你干活的工具，不该让你盲目信任。本文说明 Nomu 处理哪些数据、数据去了哪里、我们永远不会看到什么。

## 一句话总结

**不需要密钥 · 没有埋点 · 数据全部留在本地。**

## 数据去向一览

### 留在本地（你的浏览器里）

以下数据只保存在你浏览器的本地存储中，不上传到任何服务器：

- 你的店铺设置（国家、合作方代码、仓库、数量、质保、品牌）
- 你的店铺记录与当前使用的店铺
- 你的商品批次草稿
- 多账号的会话标签（按标签保存 / 恢复 Cookie）

没有服务器账户，也没有云端同步。清除浏览器数据即彻底删除。

### 只发给 Noon（你提交的内容）

以下数据在你主动提交上架时，经由你已登录的 Noon 会话发送给 Noon 平台：

- 商品信息（标题、描述、属性、价格、库存）
- 商品图片（已处理为 660×900 JPEG 白底）
- 质保与激活请求

这些请求与你在 Noon 卖家后台手动操作产生的请求相同，Nomu 只是替你执行。

### 扩展自带服务

翻译与图片处理由扩展自带的服务完成。该服务**不记录任何账号数据**——它只接收待处理的文本或图片内容，返回处理结果。

## 我们永远不会看到

- 你的 Noon 账号密码
- 任何密钥或登录授权
- 任何追踪、统计、埋点数据
- 你的浏览历史或不相关网站的 Cookie

## 权限说明

Nomu 申请以下 Chrome 权限：

| 权限     | 用途                                         |
| -------- | -------------------------------------------- |
| 标签页   | 找到你已打开的 Noon 页面并切换过去           |
| 本地存储 | 把你的店铺记录、设置与批次草稿保存在浏览器里 |
| 侧边栏   | 在 Chrome 侧边栏里显示店铺管理面板           |

### 访问的网站

| 网站                | 原因                            |
| ------------------- | ------------------------------- |
| Noon 网站           | 阿联酋 / 沙特站的商品与店铺页面 |
| Noon 合作方后台     | 商品目录管理页面                |
| Noon 图片服务       | 图片与文件上传                  |
| 1688 网站及图片服务 | 商品页采集与图片抓取            |
| 扩展自带服务        | 翻译与图片处理，不记录账号数据  |

对以上网站的访问由 URL 白名单唯一门控，白名单之外的请求一律不放行。

## 变更

- 2026-08-28：去掉 Chrome `cookies` 权限。"识别当前店铺"改走 Noon Catalog 自带的店铺列表 API（`/_vs/mp/mp-noon-merchant-api/noon-store/list`），不再由插件主动读取浏览器 Cookie。其余行为不变。
- 本政策如需更新，会在本页面记录变更。
