# Nomu 用户协议

最后更新：2026-10-03

这份协议说明：你可以用 Nomu 做什么、Nomu 会怎么处理你的内容、哪些事情不能做、出问题怎么办。**《隐私政策》是本协议不可分割的一部分**——数据存在哪里、什么时候会离开你的设备，请一并阅读 [隐私政策](/privacy/)。

本文中「Nomu」「我们」指 Nomu 扩展及其发布者；「你」「用户」指使用 Nomu 的个人或实体。

## 一、接受本协议

1. 你在官网注册 Nomu 账户、安装扩展，或以任何方式使用 Nomu，即表示你已阅读、理解并接受本协议与隐私政策；不接受前请勿使用。
2. 本协议自你注册账户起生效，此后你使用 Nomu 的每一次行为都视为继续接受本协议。
3. 你不得使用未经授权的第三方身份信息注册账户。
4. **未成年人**：不满 18 周岁的未成年人须在监护人知情同意下使用 Nomu；由监护人代为操作的，视为监护人接受本协议。

## 二、账户

1. **注册信息须真实**：用户名与邮箱应为你本人所有，且邮箱能正常接收验证码与登录链接。信息不实导致无法登录或无法找回账户，后果由你自行承担。
2. **账户凭证由你自负**：密码、邮箱验证码、邮件登录链接的保管与使用责任在你。任何人在你不知情的情况下使用上述凭证登录，视为你的操作。
3. **多设备限额**：同一账户最多可在 5 台设备上保持登录；新设备登录不会挤掉旧设备，每台设备登出只清除该设备自己的会话。超出限额前请先在旧设备登出。
4. **不得出借或转让账户**：账户不得共享、出售、转让，也不得用于绕过积分、限流或其他风控措施。违反时我们可暂停功能或终止账户。
5. **账户注销**：扩展内的「登出」仅清除本机登录态，不等于注销账户。彻底注销请邮件联系我们；注销后账户数据、积分与云端池条目的处理按 [隐私政策](/privacy/) 执行。
6. **发现异常请及时处理**：怀疑账户被他人使用，请立即修改密码并邮件联系我们。

## 三、Nomu 提供什么

Nomu 是运行在你浏览器中的扩展，主要能力包括：

- 从 1688、淘宝 / 天猫、京东、noon.com 的商品页采集商品信息；也可用右键「AI 解析商品草稿」解析任意你有权访问的页面
- AI 翻译（中 → 英 / 阿）、商品图本地白底合规处理
- 通过你已登录的 Noon 会话，逐件发布到 Noon 站点（阿联酋、沙特）
- 店铺管理、复制商品、目录浏览、条码标签打印、任务面板
- AI 助手、NomuDesign 生图与提示词优化

Nomu 替你执行你在 Noon 后台本可手动完成的操作，**但不因此获得 Noon 或任何来源平台的授权**。

### 3.1 服务依赖第三方

- Nomu 依赖 Noon 平台与 1688 / 淘宝 / 天猫 / 京东的页面结构与接口。上述站点改版、限流、封禁或调整规则都会影响 Nomu 的可用性，我们不为此承诺服务的连续可用。
- 来源站点或 Noon 对你作出的处理（限流、封号、下架、冻结资金等），由你与该平台之间解决，Nomu 不承担责任，也不代为申诉。
- 汇率换算依赖第三方汇率服务，其结果仅供定价参考。

### 3.2 不承诺结果

Nomu 的输出由规则与模型生成，**不保证完全准确、完整或合规**：

- AI 翻译、提示词优化与商品解析可能出现错译、漏译或属性误判；
- 批量发布在第一件失败时即停止，失败商品会在列表中标出，可单独重试；
- 商品能否通过 Noon 审核由 Noon 决定。标题、描述、类目、属性、价格与图片的**合规性由你负责**，发布前请自行抽检。

### 3.3 第三方模型服务商

Nomu 不自建模型，AI 能力由第三方模型服务商提供：翻译、提示词优化、助手问答与商品解析由 **DeepSeek** 执行；NomuDesign 生图按所选模型由**火山引擎方舟（豆包 Seedream）**或 **apiyi** 执行。你的账户令牌、店铺配置与批次草稿不会发送给这些服务商。

调用第三方模型意味着当次输入会离开 Nomu 交予服务商处理：商品解析包含你右键所处页面的正文与视口整屏截图，助手问答包含你的提问与该会话上下文，生图包含提示词与（可选）参考图。**请勿在上述入口提交敏感信息。** 上游服务商的日志留存与训练使用策略不由我们控制，相关条款以其官方公布的政策为准；逐类对应关系见[隐私政策](/privacy/)。

第三方服务商的可用性、中断与模型下线不由我们保证。我们可更换服务商，并按第十一条公告。
