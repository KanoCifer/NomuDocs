# Nomu Assistant

Nomu Assistant is a general-purpose assistant for Noon sellers. Ask in plain Chinese and the answer comes back word by word. When there is work to do, parsing a product for instance, it calls the tools itself.

It opens on its own page with two columns: a session sidebar on the left, the conversation on the right.

## How to open it

- Extension popup → "Nomu Assistant"
- Action menu on the Noon seller dashboard → "Nomu Assistant" (subtitle: Q&A and product parsing)

Both entries go to the same page. If it is already open you are switched to it instead of opening a second tab.

## What it can do

An empty conversation offers three example questions; click one to fill the composer:

- Why was the SKU template moved from hardcoding to a brand field?
- What is the Currency fetch interval?
- Parse this product for me

Day-to-day it splits into two shapes: **ask** (listing rules, what a field means, what to do about an error) and **have it do something** (parse a product, look something up, generate barcode labels in bulk). Whether a given question can be answered directly is decided per answer.

When the assistant has work to do, a tool-call pill lights up in its bubble, showing "Running" and then "Done" as each step goes.

Batch barcode labels are covered in full under [Barcode label printing](./barcode-labels#ask-the-assistant): supported specs, how duplicates are counted, and how many labels one call can produce.

## Reading an answer

| What you see | What it means |
| --- | --- |
| Text appears word by word | Answers show up as they generate, so long answers need no waiting |
| "Generating" | This turn is not finished yet; press "Stop" to interrupt |
| "Jump to latest" | Appears bottom-right when an answer grows long; click to snap back to the live edge |
| Tool-call pill | The assistant is working: "Running" then "Done" |
| Right of the top bar | The assistant's current connection state |

Markdown and code blocks are readable while the answer is still generating. Chinese punctuation and inline styles are handled for Chinese typography, so lines do not break out of alignment.

> Answers are generated by the Nomu Assistant, please read them critically.

## Sessions

The sidebar does three things:

- **New session**: start a clean context
- **Recent conversations**: ordered by last activity, with the first question of the thread as the title
- **Delete session**: the delete key surfaces on hover over a session row

## Sign-in

The assistant needs a signed-in Nomu account. When you are not signed in, the whole assistant page is replaced by a sign-in wall. Sign in on the [account page](./account) and come back.

Once signed in, the sidebar and message bubbles show your own username as the avatar.

| Key | Action |
| --- | --- |
| `Enter` | Send |

## Not the same as the right-click "Parse with AI" entry

Both entries have AI in the name, but they do different things:

| Dimension | Nomu Assistant | Right-click "Parse with AI" |
| --- | --- | --- |
| Trigger | Popup / action menu | Right-click on any page |
| What it does | Conversational Q&A and delegated work, including product parsing | Turns the current page into a draftable product |
| Output | An answer that comes back word by word | A product draft landed in the local batch (or pushed to the cloud pool) |
| Fits | You are mid-task and want to ask something | You hit a page with no adapter and want a draft on the spot |

Right-click parse fits "this site has no adapter but I want a draft right now". The assistant fits asking a question without leaving what you were doing.
